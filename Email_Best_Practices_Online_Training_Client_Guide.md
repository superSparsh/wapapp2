# Email Best Practices Guide  
## Online Training Campaigns — Keep Emails Out of Spam & Improve Opens

This guide outlines recommended practices for training-related emails so messages land in the inbox, get opened, and drive action.

---

## 1. How to Use Suggested Content

| Do | Don’t |
|----|--------|
| Keep the message short and clear | Use ALL CAPS or heavy punctuation (!!!) |
| Lead with value: what the learner gets, when, and how long it takes | Use spammy words like “FREE”, “Act now”, “Urgent” |
| Personalize (name, course/batch, progress) | Send generic blasts with no context |
| Match the subject line to the email body | Use misleading subjects (fake “Re:” / “Fwd:”) |
| Prefer text first, then images | Send image-only emails |
| Focus on **one** main goal per email | Ask for multiple unrelated actions |

**Tip:** Suggested content works best when it is customized with the learner’s name, course name, and next step (e.g. “Module 3 is ready”).

---

## 2. Where to Place the CTA (Call to Action)

Recommended placement:

1. **Near the top** — after 1–2 short lines (visible without scrolling on mobile)  
2. **Middle** — after key details (for readers who scroll)  
3. **End** — final reminder before the footer  

### CTA rules
- Use **one primary CTA** (one main button / one main action)
- Use clear action text, e.g.  
  - “Start Module 3”  
  - “Join Live Session”  
  - “Watch Recording”  
- Avoid vague labels like “Click here”
- Prefer HTML/CSS buttons; if using image buttons, also include a plain text link (some inboxes block images)

---

## 3. Recommended Image Dimensions

Emails should be designed for a **~600px wide** layout.

| Asset | Recommended size | Notes |
|-------|------------------|--------|
| Header / banner | **600–640px wide** | Keep file size light |
| Content image | **600px wide** | Height can vary |
| Logo | **120–200px wide** | Export 2x for retina if needed |
| CTA as image (if used) | **~200–280px × 44–50px** | HTML button is preferred |

### Image guidelines
- Keep each image ideally under **100–150 KB**
- Use **JPG** for photos, **PNG** for logos/UI
- Always add **alt text**
- Avoid large animated GIFs
- Do not rely on images alone — text must still make sense if images are blocked

**Example banner sizes:** 600×300 or 600×338

---

## 4. Recommended Content Order

Use this structure for training emails:

1. **Preview / preheader text** (shows next to the subject in the inbox)  
2. **Logo / brand** (small)  
3. **Headline** — session or benefit name  
4. **Short intro** — what it is and why it matters  
5. **Primary CTA**  
6. **Details** — date/time, duration, agenda (bullet points)  
7. **Optional tip or encouragement** (keep short)  
8. **Secondary CTA** (same action as primary)  
9. **Footer** — unsubscribe link, company details, support contact  

**Important:** Put useful text and the main CTA before heavy imagery. Image-heavy tops increase spam risk and reduce readability.

---

## 5. How to Improve Open Rates

### Subject line
- Keep around **40–60 characters**
- Be specific and personal  
  - Good: “Riya, Module 3 is live — 20 min”  
  - Avoid: “IMPORTANT TRAINING UPDATE!!!”
- Test 2 subject variants when possible

### Preview text (preheader)
- Extend the subject; don’t repeat it  
  - Subject: “Live training tomorrow”  
  - Preheader: “Agenda + join link inside — starts 11:00 AM IST”

### Sender name
- Use a recognizable name, e.g.  
  - “Acme Training”  
  - “Riya from Acme”  
- Avoid cold “noreply@…” as the only visible identity

### Timing
- Often effective: **Tue–Thu, 9–11 AM** (audience-dependent)  
- For sessions: send reminder **24 hours** and **2 hours** before

### Content hooks that drive opens
- Progress updates (“You’re 40% complete”)  
- Clear next step  
- Time-bound sessions  
- What the learner unlocks next  

### List hygiene (critical for inbox placement)
- Send only to opted-in / expected recipients  
- Remove hard bounces quickly  
- Suppress spam complainers  
- Re-engage or exclude long-inactive contacts  

---

## 6. Deliverability Essentials (Technical)

For emails to avoid spam folders, ensure:

- Domain authentication: **SPF, DKIM, and DMARC**
- A working **unsubscribe** link on every campaign email
- Clear physical/company identity in the footer
- Links on trusted HTTPS domains (avoid suspicious shorteners)
- Steady sending volume (avoid sudden large blasts from a cold domain)

---

## Quick Checklist Before Sending

- [ ] Subject is clear, short, and personalized  
- [ ] Preheader adds extra value  
- [ ] One primary CTA, placed near the top  
- [ ] Images sized for ~600px width and compressed  
- [ ] Text is readable even with images off  
- [ ] Unsubscribe + company details in footer  
- [ ] Content matches what the subject promises  
- [ ] Audience is relevant and cleaned  

---

## Summary

| Area | Best practice |
|------|----------------|
| Content | Short, personalized, one goal |
| CTA | Top + mid + end; one primary action |
| Images | ~600px wide, lightweight, with alt text |
| Order | Brand → value → CTA → details → CTA → footer |
| Opens | Strong subject + preheader + trusted sender + good timing |
