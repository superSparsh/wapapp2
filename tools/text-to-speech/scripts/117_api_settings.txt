This video covers API Settings under Account.

Open Account, then API. The page helps you manage your API token and integration endpoints. Review API docs, API Endpoint, and Your API token. If no token exists yet, generate or renew one first.

Copy the guidance that says to add parameter api underscore token equals your token on each API request, and note the example URL on screen. When you need a new secret, tap Renew Token and confirm Renew API token in the dialog. Store the new token securely — old calls fail after renew. Rotate the token if it may have been shared in chat, email, or a public repository.
